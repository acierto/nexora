# Practical examples

[Install Nexora](../docs/install.md), clone this repository, and run the commands
from its root.

| Example | Learn |
| --- | --- |
| [Local Go API](local/README.md) | Required/optional knowledge, file and agent filters, provenance, inactive rules |
| [Shared standards](shared-knowledge/README.md) | Reuse across two projects, explicit sources, additive rules, project isolation |
| [Team docs](team-docs/README.md) | Index a documentation folder, search it, and get passages next to rules with `resolve --task` |

Each collection is fictional public sample content and runs offline, including
the documentation index. It includes
configuration, complete Markdown knowledge, expected selections, and an exercise.
The example files also serve as executable integration fixtures.
